# Technology Stack

## Core Framework & Language
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict mode)
- **Framework:** [Next.js 15](https://nextjs.org/) (App Router architecture)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand) (Modular slice-based stores)

## Styling & UI
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Components:** [Radix UI](https://www.radix-ui.com/) (Primitives for accessible UI components)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)

## Backend & Persistence
- **Platform:** [Supabase](https://supabase.com/)
- **Database:** PostgreSQL
- **Authentication:** Supabase Auth with Google OAuth
- **Storage:** Supabase Storage (Character portraits, companion images)

## Testing & Quality Assurance
- **Unit/Integration Testing:** [Vitest](https://vitest.dev/)
- **E2E/Visual Testing:** [Playwright](https://playwright.dev/)
- **Code Quality:** ESLint

## Specialized Tools
- **3D Dice Engine:** [@3d-dice/dice-box](https://github.com/3d-dice/dice-box)
- **Natural Language Parsing:** Custom NLU implementation for SRD content

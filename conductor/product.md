# Initial Concept
This is a mobile-first digital character sheet for the Daggerheart TTRPG, built to automate the math and modifiers of the game while providing real-time synchronization between players and Game Masters.

# Product Definition

## Target Audience
- **The Strixhaven Campaign (Family & Friends):** The primary users are the developer's family and gaming group, focusing on ease of use for relatively inexperienced players.
- **The Daggerheart Community:** While built for personal use, the project is free and open-source for any players needing a mobile-first digital sheet.
- **Game Masters (GMs):** Tools for GMs to monitor party vitals, manage Fear, and coordinate campaigns in real-time.

## Core Goals
- **Automated Mechanics:** Providing a "math-free" experience by automatically calculating modifiers, bonuses, and derived stats from domain cards and features.
- **Real-Time Synchronization:** Ensuring seamless data flow between players and GMs during active game sessions, especially for remote play.
- **Strategic Evolution:** Moving towards a robust homebrew sharing system and eventual offline support.

## Key Features & Roadmap
- **Deepened Homebrew System:** Enabling the creation and sharing of custom items, spells, and features within campaigns.
- **Enhanced Rule Integration:** Adding SRD-based tooltips and interactive guides to help players learn and reference rules on the fly.
- **Dynamic Views:** Implementing a mobile-first dark-theme UI with streamlined default views that can be expanded for greater complexity.

## Visual Identity & UX
- **Mobile-First Dark Theme:** A sleek, high-contrast interface optimized for mobile devices.
- **Streamlined Complexity:** Utilizing a "hidden-by-default" design philosophy where complex data is accessible through expansion rather than cluttering the main view.

## Content Management Strategy
- **NLU-First Automation:** Leveraging Natural Language Understanding to parse SRD content into interactive mechanics.
- **Hybrid Accuracy:** Combining automated parsing with manual overrides for 100% accuracy on complex features.
- **User-Driven Corrections:** Using the homebrew system as a "last resort" mechanism for users to correct or customize game data.
